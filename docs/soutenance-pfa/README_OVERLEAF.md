# Soutenance PFA LexHub — Présentation Beamer Overleaf (ENSA Tétouan / UAE)

Cette archive contient la présentation officielle de soutenance de **Projet de Fin d'Année (PFA)** pour **LexHub**, formatée selon la charte graphique Beamer officielle de l'**Université Abdelmalek Essaâdi (UAE) et de l'École Nationale des Sciences Appliquées de Tétouan (ENSA)**.

---

## 1. Importation rapide sur Overleaf (1 clic)

1. Rendez-vous sur votre compte **Overleaf** ([https://www.overleaf.com](https://www.overleaf.com)).
2. Cliquez sur **New Project** $\rightarrow$ **Upload Project**.
3. Sélectionnez le fichier ZIP : **`Soutenance_PFA_LexHub_ENSA_Overleaf.zip`**.
4. Le fichier principal est **`main.tex`**.
5. Cliquez sur **Recompile** (avec le compilateur par défaut **pdfLaTeX**).

---

## 2. Structure des fichiers inclus

| Fichier / Dossier | Rôle & Description |
| :--- | :--- |
| **`main.tex`** | Fichier LaTeX principal contenant les 25 diapositives de la soutenance |
| **`beamerthemeuae.sty`** | Thème Beamer principal UAE / ENSA Tétouan |
| **`beamercolorthemeuae.sty`** | Palette de couleurs officielles (Bleu nuit, Bleu ciel, Or UAE) |
| **`beamerinnerthemeuae.sty`** | Style des blocs, badges et éléments graphiques |
| **`beamerouterthemeuae.sty`** | En-tête avec bannière universitaire, pied de page et barre de progression |
| **`logo_uae_ensa.png`** | Logo officiel combiné Université Abdelmalek Essaâdi & ENSA Tétouan |
| **`logo-webvoice.png`** | Logo de l'entreprise d'accueil WEBVOICE (Tanger) |
| **`logo-lexhub.png`** | Logo de la plateforme LexHub |
| **`screenshots/`** | Dossier contenant les captures d'écran réelles de la production |

---

## 3. Paramètres de compilation Overleaf

* **Compiler :** `pdfLaTeX` (Menu Overleaf en haut à gauche $\rightarrow$ Compiler $\rightarrow$ pdfLaTeX).
* **TeX Live version :** 2023, 2024 ou plus récent.
* **Format d'écran :** 16:9 (`aspectratio=169`), adapté à tous les vidéoprojecteurs modernes de soutenance.
