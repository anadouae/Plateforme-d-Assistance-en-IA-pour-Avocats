\section{Déploiement et intégration continue (CI/CD)}
\label{sec:cicd}

La production s'appuie sur Caddy, Docker Compose et Alembic. GitHub Actions publie les images \texttt{frontend}, \texttt{backend} et \texttt{celery} vers GHCR. Cette chaîne est livrée ; les perspectives du chapitre~\ref{ch:conclusion} concernent le produit.

\section{Résultats obtenus}

L'atelier en cinq étapes, l'export officiel, la règle « validé = visible par l'assistant », l'isolation multi-tenant et le modèle économique du chapitre~\ref{ch:economie} sont en production. Le paiement marchand réel n'est pas encore activé.

\section{Risques et limites}
\label{sec:limites}

\begin{enumerate}[leftmargin=1.4em]
  \item Un micro faible dégrade la transcription : la relecture (marques orange) reste obligatoire.
  \item La dictée et la rédaction dépendent d'APIs cloud.
  \item La correction de forme n'est pas une vérification juridique.
  \item LexHub n'intègre pas Mahakim et n'est pas un ERP de facturation.
  \item L'avocat reste responsable du contenu.
\end{enumerate}
