# Guide pas à pas — tester une plaidoirie famille sur LexHub

Site : https://lexhub.space  
Chrome recommandé pour le micro.  
Documents **fictifs** : ne pas les déposer au greffe.

## 1. Connexion

1. Ouvrir https://lexhub.space → Connexion.
2. Si un bandeau « compte mémorisé » apparaît : **Se connecter avec un autre compte**, puis saisir le compte de test.
3. Compte cabinet de démo : voir le *Guide d’utilisation & tests* remis à l’encadrant (ne pas coller les mots de passe dans le rapport PFA).

## 2. Créer le dossier (aides jaunes)

1. Menu **Dossiers** → **Nouveau dossier**.
2. Cliquez chaque champ : une aide jaune explique *pourquoi* et donne un *exemple*.
3. Recopiez `00_FICHE_DOSSIER.txt` :
   - Client : فاطمة العلمي
   - Matière : **Famille**
   - Ville : **Rabat**
   - Tribunal : TPI Rabat
   - Rôle : demandeur / مدّعية
   - Adverse : كريم بنجلون (ou كريم بناني si vous restez sur les pièces Word déjà générées)
   - RG : `2024/120` (facultatif)
   - Chambre : قسم قضاء الأسرة
4. **Créer le dossier**.

## 3. Déposer les pièces

Dans le dossier ouvert → Documents / pièces :

1. `01_Acte_mariage_Fatima_Alami.docx`
2. `02_Extrait_naissance_Youssef.docx`
3. `03_Requete_nafaka_hadana.docx`
4. `05_Mise_en_demeure.docx` (si généré)

Attendre l’indexation (OCR). Ouvrir un aperçu pour vérifier le texte arabe.

## 4. Nouvelle plaidoirie

1. Menu **Plaidoiries** → **Nouvelle plaidoirie**.
2. S’il reste un vieux brouillon : **Commencer une nouvelle** (pas Reprendre).
3. Étape 1 : lier **ce** dossier famille.
4. Étape 2 : micro → lire à voix haute `04_Texte_dictée_à_lire_à_voix_haute.txt`  
   (version courte : `06_Dictee_courte.txt`).
5. Arrêter → **Corriger**.
6. Si le texte n’est que du bruit (`k;k;l;`) : le site refuse — c’est normal.
7. **Rédaction IA** → relire → Export Word / PDF.

## 5. Ce que vous devez voir

- Transcription proche de ce que vous avez lu (forme fusha).
- Pas d’invention d’un autre enfant, d’un autre montant, d’un autre tribunal.
- Word / PDF avec en-tête cabinet si le logo est renseigné.

## 6. Assistant (optionnel)

Valider la plaidoirie : l’assistant du cabinet la voit en lecture / export, sans synthèse IA.
